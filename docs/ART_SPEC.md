# 美术规格（ART SPEC）

## 风格方向

- **关键词**：清新、明亮、日式动漫、柔和。参考：双星物语的 3/4 俯视角色比例，塞尔达梦幻沙漏的明快配色。
- **视角**：俯视 3/4（能看到物体正面和顶面），光源统一来自**左上**，阴影落在右下。
- **配色**：低饱和粉彩为主。草地黄绿 `#9fdc8a`、水 `#7ccbe8`、屋顶珊瑚粉 `#e58f8f`、描边深青灰 `#3a4a52`（不要用纯黑描边）。
- **描边**：角色/敌人 1.5–2px 深青灰描边；地面瓦片不描边；物体可选细描边。
- **角色比例**：Q 版 2.5 头身，大眼睛，头约占身高 45%。
- **分辨率**：基础网格 32px。非像素风（矢量/手绘均可），游戏不开 pixelArt 模式。

## 文件格式

- **首选 SVG**（Cursor 可以直接写代码生成，清晰、可改），放 `public/assets/<分类>/`，manifest 用 `type: 'svg'`，并在 SVG 根节点写明 `width`/`height`（= 下表尺寸）。
- 也可以 PNG（透明背景）。需要逐帧动画的角色用 PNG spritesheet（或带 width/height 的 SVG 拼图）。
- 文件名：小写下划线，如 `assets/tiles/grass_1.svg`。

## 接入步骤

1. 画好文件放到 `public/assets/...`
2. 在 `src/art/manifest.ts` 的 `ASSETS` 里加一行，**key 与下表一致**
3. `npm run dev` 看效果；加载失败会自动回落占位图（控制台有警告）

## 锚点约定

- **地面瓦片**：32×32，铺满，无透明边，四边要能无缝拼接。
- **物体/角色/敌人**：底边中点 = 脚底/落地点。图像底部留 0–2px，不要留大片透明。
- **特效**：中心锚点。`fx_slash` 朝**右**画（代码会旋转到攻击方向）；`fx_wind_blade` 也朝右。

## 角色 spritesheet 布局

帧 32×48，4 列 × 4 行，整图 128×192：

| 行 | 方向 | 列 0 | 列 1–3 |
|---|---|---|---|
| 0 | 朝下 down | 站立 | 走路循环 |
| 1 | 朝左 left | 站立 | 走路循环 |
| 2 | 朝右 right | 站立 | 走路循环 |
| 3 | 朝上 up | 站立 | 走路循环 |

manifest：`{ key: 'player', type: 'spritesheet', url: 'assets/characters/player.png', frameWidth: 32, frameHeight: 48 }`。
### 动作帧（可选，v0.3 起支持）

在行走 4 行下面继续加行，每个动作 4 行（down/left/right/up）× 4 帧，播放一次（16fps ≈ 0.25 秒）：

| 行 | 内容 | 整图尺寸 |
|---|---|---|
| 4–7 | `attack` 攻击挥砍 | 128×384 |
| 8–11 | `cast` 施法（技能 JSON 里写 `"anim": "cast"` 的技能使用） | 128×576 |

释放技能时自动播放 `<key>_<动作>_<方向>`；没有对应行就跳过，不影响游戏。敌人同样适用。

满足 16 帧时代码自动创建 `player_walk_down` 等动画；否则退化为单帧 + 程序化弹跳。NPC / 敌人同理（敌人帧尺寸用下表尺寸）。
