# CONTENT-02 · 湖畔地图 `lake`
**类型**：内容　**依赖**：无

## 目标
翠风森林北出口指向 `lake`（出生点 `from_forest`）。做一张宁静的湖畔地图。

## 内容要求
- 尺寸约 64×44。中央大湖，环湖小路，一座木桥通往湖心小岛，岛上放一颗技能宝珠（可以用 CONTENT-03 新技能，或暂用 `heal` 以外的已有技能 —— 注意已习得的技能拾取后只会消失不会重复学）。
- 出生点：`default`、`from_forest`（南侧入口内）。
- 出口：南边回森林 → `{ "to": "forest", "spawn": "from_lake" }`（森林已有该出生点）。
- 敌人 8–10 个，湖边可以用 `"tint": "#e0f0ff"` 做清晨色调。

## 验收标准
- [ ] `npm run validate` 0 错误
- [ ] 森林 ⇄ 湖畔 双向可走通，小岛可到达
- [ ] `npm run build` 通过
