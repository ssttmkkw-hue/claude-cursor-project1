# ART-02 · 自然物体
**类型**：美术　**依赖**：无

## 目标
树、松树、灌木、石头的正式美术。它们数量最多，决定森林的观感。

## 涉及文件
`public/assets/objects/*.svg`、`src/art/manifest.ts`

## 规格
| key | 尺寸 | 要点 |
|---|---|---|
| `obj_tree` | 64×80 | 圆润树冠，左上高光，树干底部在底边中点，树冠可宽于一格 |
| `obj_pine` | 48×80 | 松树，层叠三角 |
| `obj_bush` | 32×32 | 灌木，可点缀小花 |
| `obj_rock` | 32×32 | 灰蓝圆石，带苔藓点缀 |

- 底边中点 = 落地点；底部不留空白。
- 树冠里不要画影子到地面上（影子以后统一处理）；可以在树干底部画一小块深色接地阴影。

## 验收标准
- [ ] 4 个 key 登记并正常显示
- [ ] 森林里树木密集处层次清楚，角色走到树后被正确遮挡
- [ ] `npm run build` 通过

## 注意
可选加分：做 2 个树的变体（`obj_tree_b` 等），在 `src/data/tiles.json` 新增物体类型并分配新字符，再改森林地图使用。新增类型需同时在 `placeholders.ts` 加占位图。
