# ART-03 · 村庄建筑与道具
**类型**：美术　**依赖**：无

## 目标
房子、栅栏、告示牌、水井。

## 涉及文件
`public/assets/objects/*.svg`、`src/art/manifest.ts`

## 规格
| key | 尺寸 | 要点 |
|---|---|---|
| `obj_house` | 96×112 | 占地 3×2 格（底部 96×64 是墙体/门所在），上方是屋顶。珊瑚粉屋顶、奶白墙、木门在正中、两扇窗 |
| `obj_fence` | 32×32 | 横向木栅栏，左右边缘可拼接 |
| `obj_sign` | 32×40 | 木告示牌 |
| `obj_well` | 32×48 | 带小屋顶的石井 |

## 验收标准
- [ ] 4 个 key 登记并正常显示
- [ ] 房子门的位置与地图上门前的土路对齐（门在底边正中）
- [ ] `npm run build` 通过

## 注意
可选：再做 1–2 种房子变体（不同屋顶颜色），作为新物体类型加入 `tiles.json`。
