# 路线图

开发方式：**做一个能玩的版本 → 打 tag 备份 → 继续升级**。

## 备份方式

每个版本完成后：
```bash
git tag -a v0.1.0 -m "基础框架"
```
```bash
git push origin v0.1.0
```
回到某个版本：`git checkout v0.1.0`（只读查看）或 `git switch -c restore-v0.1.0 v0.1.0`。

## v0.3.0 · 系统深化（Claude 核心 + Cursor 内容，两边并行）
- Claude（核心，分支 `claude/...`）：
  1. 状态效果（减速/中毒/冰冻/眩晕），技能 JSON 可挂 `status`
  2. 事件/剧情脚本：对话分支选项、flag 条件、给技能/回血/开门等动作，NPC 对话按剧情进度变化
  3. 门与室内：按 E 进入的出口、宝箱、开关/机关门
  4. Boss 框架：多阶段 AI、Boss 血条事件、击败后写 flag

- Cursor（`docs/cursor-lines/SOLO-2.md`）：受击音效、动作帧、对话头像、敌人动画、手柄菜单导航、洞穴地图等（只依赖已有接口）
